📊 ESTRUCTURA DE DATOS
════════════════════════════════════════════════════════════════════════════

ANTES: localStorage (público)
└─ appData: JSON con todos los datos

AHORA: SQLite (privado por usuario)
├─ usuarios
│  ├─ id
│  ├─ usuario (único)
│  ├─ email (único)
│  ├─ password_hash
│  └─ created_at
└─ app_data
   ├─ id
   ├─ usuario_id (relación con usuarios)
   ├─ data (JSON con productos, ventas, etc)
   └─ updated_at


🔄 FLUJO DE AUTENTICACIÓN
════════════════════════════════════════════════════════════════════════════

Usuario Accede
     ↓
Verifica Token en localStorage
     ↓
¿Token válido? → SÍ → Carga Dashboard
     ↓ NO
Muestra Modal de Login
     ↓
Usuario Completa Formulario
     ↓
Servidor Valida Credenciales
     ↓
Genera JWT Token
     ↓
Almacena Token en localStorage
     ↓
Carga Dashboard
     ↓
Todas las peticiones incluyen token
     ↓
Servidor Verifica Token en cada solicitud
     ↓
Al Cerrar: Limpia Token y Vuelve a Login
